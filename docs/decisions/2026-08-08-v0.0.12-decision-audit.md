# v0.0.12 decision audit: production-readiness coverage

Status: audit note, not a feature decision
Date: 2026-08-08
Scope: every `docs/decisions/2026-08-08-*.md` file that existed before this audit, reviewed against `planning/gaps5.md` and the TaskFlow gap tasks.

## Audit rules

1. A decision file can close a planning question, but it does not close the production gap until the implementation, tests, docs, and release gates exist.
2. Drafts must name real existing seams and the missing work. If a doc mentions auth, it must include the broader identity surface: OIDC, SAML where relevant, social providers, MFA, device/session inventory, and device/client flows.
3. v0.1 adoption means Stage 1 framework plus Stage 2 self-hosted platform posture. Stage 3 managed-cloud items are allowed to stay deferred if the seam is designed and the docs say so plainly.

## Changes made in this audit

- Replaced ambiguous top-level `Closes:` headers with `Decision coverage:` in draft design docs, so the wording no longer implies code has shipped.
- Expanded `2026-08-08-enterprise-identity-design.md` to include the missing social-login provider catalog and OAuth 2.0 Device Authorization Grant.
- Expanded `2026-08-08-enterprise-preset-design.md` with an identity hardening profile for OAuth/social providers, SSO, MFA, session/device inventory, and client attestation.
- Added a v0.0.12 to v0.1 adoption gate to `2026-08-08-product-north-star.md`.
