## CRITICAL

1. [ ] **[CRITICAL] umbral-storage — media proxy passes unvalidated decoded keys to the backend (arbitrary file read)** — the gated media proxy percent-decodes the request path and hands the key straight to the storage backend; with `FsStorage` via `media_with_storage` (or any path-joining backend) a gate-admitted caller reads arbitrary files: `GET /files/%2Fetc%2Fpasswd` (also `..%2F` escapes; `path_for` is a bare `dir.join`, which an absolute key replaces). The decode itself was review_3's correct fix; the missing piece is validation between decode and backend. **Fix:** make `key_for_path` fail closed — reject a leading `/`, any `..` segment, backslashes and NUL (extending its existing fail-closed UTF-8 posture) — and never let `join` take an absolute key. *(src: review_4/umbral-storage.md STORAGE-1; coordinator-verified)*
